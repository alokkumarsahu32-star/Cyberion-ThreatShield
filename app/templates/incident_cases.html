CASE-01 HIGH — Analytical Priority

LSASS Credential Dumping Investigation

Status: Completed — Offline Dataset Analysis

ATT&CK: T1003.001 — LSASS Memory

Evidence: Sysmon Event ID 10 and Event ID 11

Investigation Summary

Investigated LSASS process access and subsequent dump-file creation using process-level correlation within a 60-second window.

Key Findings

  • LSASS access and dump-file event pairs: 16
  • Unique process-level correlations: 6
  • Observed processes included ProcDump, Outflank-Dumpert, rundll32 and taskmgr.
  • Correlated activity was observed across multiple dataset hosts.

Analyst Assessment

The observed correlations warrant investigation for possible credential-dumping activity. Event correlation alone does not prove successful credential extraction or a confirmed compromise.

CASE-02 MEDIUM — Analytical Priority

Windows Security Audit Log Clearing Investigation

Status: Completed — Offline Dataset Analysis

ATT&CK: T1070.001 — Clear Windows Event Logs (Provisional Mapping)

Evidence: Windows Security Event ID 1102

Investigation Summary

Investigated Windows Security audit log-clearing events in the offline dataset to identify potentially relevant activity and its context.

Key Findings

  • Dataset records analyzed: 4,633
  • Event ID 1102 records: 21
  • Distinct source EVTX files: 21
  • Equivalent Python condition matched all 21 observed Event ID 1102 records.

Analyst Assessment

Security log clearing can be relevant to defense evasion, but authorized administration, maintenance and incident response can also produce this event. The dataset labels do not independently establish malicious intent.
Report: CASE-02-WINDOWS-SECURITY-LOG-CLEARING.md
