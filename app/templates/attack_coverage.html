Coverage Methodology

  • Sigma coverage counts explicit ATT&CK technique tags in YAML rules.
  • Log Analyzer coverage is listed separately and requires dedicated test evidence.
  • Each unique technique is counted once, even when multiple rules reference it.
  • Hunt and response playbook references are not counted as additional verified techniques.
  • The project target is 20+ unique documented techniques.
